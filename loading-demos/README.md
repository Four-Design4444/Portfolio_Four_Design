# Loading 入场动画原型（Demo Only）

独立原型，与 `src/` 完全无关，看完可直接删除整个 `loading-demos/` 文件夹。

## 预览方式

文件已把 Rany 字体以 base64 内嵌，完全自包含、离线可用：

- **直接双击打开任意 `demo-*.html` 即可**（推荐，不依赖任何服务）
- 或起静态服务后访问 `/loading-demos/index.html` 总览页

## 四个方向

| 文件 | 概念 | 一句话 |
| --- | --- | --- |
| `demo-1-logo-stroke.html` | Logo 描边 | FOUR 字标以线条勾勒成型，最后填充定稿 |
| `demo-2-starfield.html` | 星尘汇聚 | 呼应首页星空粒子，数字计数 + 粒子向心汇聚 |
| `demo-3-blur-focus.html` | 对焦成型 | 与首页 hero 的 BlurText 入场同一语言，F/O/U/R 逐字由虚到实 |
| `demo-4-minimal-line.html` | 极简开合 | 大数字计数 + 中线生长，结束时画面如幕布向两侧打开 |

每个 demo 结尾都会演示「交接给首页」的动画（黑色幕布退场 → 首页 hero 模拟画面入场），右上角有 Replay 可反复重看。
